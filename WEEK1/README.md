############################# VAPT TASK 1 #############################

This task provides hands-on exposure to the core principles and practices of penetration testing. 
It focuses on building practical skills through the use of industry-standard tools, methodologies, and frameworks commonly applied in real-world security assessments.
The objective is to develop a comprehensive understanding of offensive security concepts, including vulnerability identification, risk analysis, and structured reporting, while adhering to recognized security standards and compliance requirements.

The primary objectives of this task are to:

Develop hands-on experience with industry-standard penetration testing and security assessment tools
Apply recognized penetration testing methodologies used in professional engagements
Understand and evaluate common security vulnerabilities and misconfigurations
Perform structured analysis and risk assessment based on identified findings
Produce professional-grade security reports suitable for stakeholders, clients, and technical teams
Gain awareness of relevant security standards, best practices, and compliance frameworks

This task introduces and reinforces the use of a range of tools commonly employed in professional penetration testing and security assessments such as OpenVas,Metasploit for gaining access,Burp Suite, Sqlmap, etc.
which are used to support activities such as reconnaissance, vulnerability identification, exploitation validation, and reporting.

As part of the learning process, this task incorporates the analysis of real-world security incidents and attack scenarios, such as the SolarWinds supply chain attack. 
These case studies are used to examine attacker techniques, attack paths, detection gaps, and response challenges.
